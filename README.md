# ArtOS

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**ArtOS** — коллекция примеров «Hello, World!» на разных языках программирования. Тестовый проект для практики Git, GitHub/GitVerse и GPG-подписи коммитов.

## 📂 Структура

```
hello-world/
├── java/
├── cpp/
├── csharp/
├── pascal/
├── python/
├── php/
├── go/
└── javascript/
```

## 🚀 Запуск

| Язык | Команда |
|------|---------|
| Java | `cd java && javac HelloWorld.java && java HelloWorld` |
| C++ | `cd cpp && g++ hello.cpp -o hello && ./hello` |
| C# | `cd csharp && dotnet run` |
| Pascal | `cd pascal && fpc hello.pas && ./hello` |
| Python | `python3 python/hello.py` |
| PHP | `php php/hello.php` |
| Go | `cd go && go run hello.go` |
| JavaScript | `node javascript/hello.js` |

## 🔐 Безопасность
